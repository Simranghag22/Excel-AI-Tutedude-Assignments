# Assignment 1 — Getting Started with Excel

This was my first assignment for the certification, so I kept it simple and focused on just getting comfortable moving around Excel again — navigating sheets, editing cells, and cleaning up my workspace.

## What I Did

I built a small **Inventory_List** with Item_ID, Product_Name, and Quantity columns, and used it to practice the basics: jumping around with the Name Box and `Ctrl+Arrow`/`Ctrl+Home`, renaming sheet tabs, and entering data cleanly.

Alongside that, I added a separate **Data_Entry_Rules** sheet where I noted down the rules I wanted to follow when adding new inventory entries — this was mainly to practice thinking about data structure before just typing values in.

For Task 3, I exported the completed sheet as a PDF, just to get used to that workflow since it's something I'll likely need for sharing reports later.

I also spent some time customizing my **Quick Access Toolbar**, adding the commands I use constantly (Save, Undo, Redo, Sort, Filter) so I'm not hunting through ribbon tabs every time.
